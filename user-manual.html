🔄 Complete Clinical Workflow
  1. 1
    Create Patient — Name, DOB, notes. Tap + New Patient from Patient List.
  2. 2
    Add Eye Record — Enter K1/K2 powers & axes, IOL power, IOL cylinder, target axis, SIA.
  3. 3
    Run Toric Calculator — Enable PCA toggle if no posterior corneal data. Review target axis & residual astigmatism.
  4. 4
    Capture Eye Photo — Align limbus to gold ring, pupil to cyan ring. Wait for LEVEL in centre, then tap shutter.
  5. 5
    Annotate Landmarks — Tap vessels on photo to mark reference points. Tap Save. (Compensates for intraoperative cyclorotation.)
  6. 6
    Align IOL — Use Alignment Screen overlay in OR. Match IOL marks to green target axis line.
  7. 7
    Post-op Analysis — Enter post-op refraction in Alpins screen. Review CI, ME, AE, IS metrics.
  8. 8
    Log SIA Case — Add case to SIA Nomogram to build personal surgeon profile over time.

🧮 Toric Calculator
  • Pre-populates from eye record automatically
  • PCA Toggle — adds Barrett posterior corneal ATR contribution (≈+0.3 D) using double-angle vectors. Enable unless you have Pentacam TCRP data.
  • Post-Refractive banner — shown when eye had prior LASIK/PRK/RK. Use Barrett True-K or Haigis-L instead.
  • Rotation Effect Chart — residual vs. IOL rotation 0°–30°. Steep slope = sensitivity to rotation.
  • Export Plan — generates PDF with biometry, axes, rotation chart. Share via email/AirDrop.
// PCA double-angle correction
Tx = Ax + 0.3 | Ty = Ay
mag = √(Tx²+Ty²)
axis = ½·atan2(Ty,Tx)·180/π [mod 180]

📌 Landmark Annotation
  • Tap on the eye photo to place a marker (ring + dot + number)
  • Colours cycle: red → gold → green → blue → pink → orange
  • Undo Last — removes most recent marker
  • Clear All — removes all markers
  • Tap Save — markers persist on alignment overlay
Mark 3–4 distinct conjunctival vessels at different clock positions (e.g. 3h, 6h, 9h). Avoid marking the limbus itself.

📈 SIA Nomogram Tracker
  • Access via Patient List → SIA button
  • Log each case: planned SIA magnitude/axis + achieved SIA magnitude/axis
  • App calculates vector mean across all cases
  • Case accuracy colour coding: ≤0.25 D · ≤0.50 D · >0.50 D
Build ≥20 cases before using mean SIA in routine calculations. Consider separate profiles for different incision sites.

Calculator result incorrect K1 entered as steeper meridian K1 = flat (lower D); K2 = steep (higher D). Swap if needed.
Alpins CI very high (>2) SIA uses IOL cylinder default Enter actual post-op refraction cylinder for real analysis
Landmarks missing on alignment Not saved before exiting Re-open Landmark Annotation and tap Save
PCA toggle not visible K values missing from eye record Fill K1 Power, K1 Axis, and K2 Power in the eye record first
PDF export fails No share target installed Restart app; ensure Files or email app is available
